# Triage labels

Use these GitHub labels when a skill refers to a triage role.

| Role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Needs maintainer evaluation |
| `needs-info` | `needs-info` | Waiting for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified for an agent |
| `ready-for-human` | `ready-for-human` | Ready for a human to implement |
| `wontfix` | `wontfix` | The maintainer has declined the work |
